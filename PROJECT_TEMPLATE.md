# PROJECT CONTROL DOCUMENT

## Rules
- Only one task may be IN_PROGRESS at a time
- Tasks must move: TODO → IN_PROGRESS → VERIFY → DONE (or BLOCKED)
- DONE requires verification and evidence
- Epics never have status
- Tasks are completed in order unless BLOCKED

## Task Selection Rules
1. If any task is IN_PROGRESS or VERIFY, stop
2. Select the first TODO task not BLOCKED
3. Confirm prerequisites
4. Move task to IN_PROGRESS
5. Execute work
6. Provide evidence
7. Move to VERIFY
8. Verify before DONE
